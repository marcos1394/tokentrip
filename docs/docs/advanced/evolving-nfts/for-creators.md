# Evolving NFTs: Guide for Creators

As a provider on TokenTrip, you have the power to create dynamic experiences that engage your community long after the initial sale.

### Defining Evolution Rules

When you create a new experience via the "Mint Experience" page, you will see an "Dynamic Evolutions (Optional)" section. Here, you can add one or more rules for your NFT.

For each rule, you will define:

1.  **Trigger Type:**
    * **Time-Based:** Select this if you want the NFT to change on a specific date.
    * **Goal-Based:** Select this for evolutions based on on-chain metrics. For now, this is tied to your provider profile's `total_reviews` count.

2.  **Trigger Value:**
    * For **Time-Based** triggers, you will pick a future date from a calendar.
    * For **Goal-Based** triggers, you will enter a number (e.g., `50` for 50 reviews).

3.  **New Metadata:**
    * **New Image URL:** The image the NFT will evolve into.
    * **New Description:** The new description for the evolved NFT.
    * **Attributes to Add:** You can add new traits to the NFT upon evolution (e.g., a "Legendary" status).

These rules are permanently embedded into the NFT at the time of minting and cannot be changed, providing a transparent and trustless contract with your collectors.
